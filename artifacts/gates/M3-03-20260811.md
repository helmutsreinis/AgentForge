## Security and portability review

`IModelContextPreparer` snapshots messages, content records, attachment metadata, tools,
response format, and limits before asynchronous enumeration. It applies the shared bounded
canonical redactor to text, attachment filenames, tool arguments/results, and descriptions.
Identity/correlation fields or JSON schemas that trigger redaction are denied because changing
them could change authority or invalidate the contract. Oversized, malformed, null, or hostile
input returns fixed typed text without copying source material. The original request remains
unchanged. Started evidence pins policy/count, and its input hash covers prepared content.

Hosted construction requires exact profile/descriptor ID, type, model, HTTPS endpoint,
capability posture, version, configured store, and reference. The stored object retains only
the reference. Materialization happens only after the consumer advances beyond started
evidence. Bearer values are limited to 8,192 visible ASCII characters; whitespace, control,
non-ASCII, CR/LF, NUL, empty, and oversized values fail without HTTP. `finally` removes the
authorization header and clears the lease immediately after `SendAsync`, including transport
failure/cancellation. The BCL creates a transient managed header string that cannot be zeroed;
dropping its header reference immediately after send is the documented residual limitation.

All logic is BCL/AgentForge-contract based and passes identically on Windows and Ubuntu.
No credential, endpoint, raw context, provider error body, or live response is persisted in
tests or this report. The live gate remains credential-free and process-scoped.
