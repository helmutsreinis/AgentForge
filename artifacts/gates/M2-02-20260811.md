## Security and portability review

Parameter JSON is bounded to 64 KiB and depth 32, must be an object, rejects duplicate
properties, and is canonicalized without evaluating content. Filesystem targets and
workspaces are fully qualified; URI targets reject user information. Raw parameters,
targets, and workspaces exist only for the invocation/preview and cross persistence and
audit as hashes or structured-redacted data. The CLI refuses parameter command-line
arguments and requires redirected stdin.

Approval requires a `Ready` installation and the matching OS-materialized local
administrator credential. Policy is reconstructed from the exact current durable agent
version. Missing/ambiguous rules deny, configured grants still require approval, and a
denied or already-allowed policy cannot be overridden. Preview binds current policy,
decision, expiry, approver, and correlation; apply repeats evaluation and fixed-time hash
comparison. The unique installation/key constraint and exact authenticated replay checks
cover concurrent/retried delivery.

Windows exercises live current-user DPAPI. Ubuntu uses deterministic secret-store service
fixtures because Secret Service is session-gated; all domain, persistence, migration,
redaction, and policy behavior is identical. UTC ticks avoid unsupported SQLite
`DateTimeOffset` ordering. No OS-specific code enters Domain or Abstractions.

## Remaining findings

- The restricted executor must derive risk/capability/tool/version from an immutable
  authoritative descriptor, enforce containment and resource limits, re-evaluate current
  policy, and atomically consume an exact grant before starting a process.
- Approval evidence alone never makes passive inventory callable. Version/help probing
  remains disabled.
- Revocation/consumption domain transitions exist; authenticated persistence paths are
  intentionally deferred until invocation/revocation workflows can commit their audit
  evidence atomically.
- Docker is unavailable locally, so container isolation remains a named later gate.
