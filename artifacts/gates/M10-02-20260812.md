- Discovery reads manifests and assemblies only; no candidate assembly is loaded.
- Signature presence is not trust. The signature verifier result and low risk are both required in-process.
- Production verification requires an exact configured ECDSA P-256 public key, key ID, algorithm, and canonical manifest payload; an empty key catalog trusts nothing.
- Post-discovery hash changes fail with a concurrency conflict.
- All other plugins require a container worker with denied network and filesystem/resource/process isolation; the
  digest-pinned adapter may satisfy it and absent configuration fails typed.
- The worker and SDK target self-contained .NET 10 Windows and Linux release packaging.
