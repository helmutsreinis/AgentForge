## Security and portability review

Heartbeat possession requires the exact worker owner and 43-character base64url lease token. The
domain hashes the supplied token and compares it to SQLite evidence in fixed time. Heartbeat time
must advance but remain at/before the immutable expiry; only the run version advances. The raw token
is not passed to redaction/audit/persistence and byte-scan fixtures prove representative values are
absent.

Recovery requires exact run and attempt versions and cannot act before expiry. Completion is pinned
to the persisted expiry rather than caller time, uses only persisted usage/stream evidence, remains
retryable, and retains lease hashes/times. Run/attempt mutation, exact ledger release, provider-
health mutation, and recovery audit share one unit of work. Early, duplicate, stale, missing-ledger,
or health-version conflict cannot partially release work.

Observed health is limited to one optimistic-concurrency row per exact profile with installation,
run, attempt, actor, and correlation provenance. Success produces five-minute healthy evidence and
resets failures. Retryable provider failure or expiry produces 15-minute unavailable evidence and a
five-second exponential probe-retry time capped at five minutes; count caps at 1,000. Cancellation,
budget, policy, and unsupported outcomes write no provider judgment. Route planning continues to
fail closed on missing, unavailable, unknown, future, or expired evidence.

Windows and Linux share the same domain, application, and repository behavior. Migration 0011 adds
no OS-specific field and fabricates no observation. The generated down migration is destructive and
is not an operational rollback.

## Remaining findings

- Recovery is an internal exact-run service. There is no background expired-lease scanner,

- Only one attempt exists. Retryable failures do not yet create a next attempt, retain a complete

- Temporary-unavailable evidence needs a later bounded probe/operator observation to become healthy;
  expiry never silently promotes missing evidence.
- Hosted profile construction still needs destination DNS/IP rebinding controls before production
  catalog composition. The default provider catalog is empty.
- Docker remains unavailable locally, so the independent live container/namespace gate stays open.
