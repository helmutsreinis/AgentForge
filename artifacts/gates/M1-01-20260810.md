## Findings resolved during the gate

Ubuntu restore detected high-severity advisory `GHSA-2m69-gcr7-jv3q` in transitive
`SQLitePCLRaw.lib.e_sqlite3` 2.1.11. Stable bundle 2.1.12 is now directly pinned;
advisory suppression was not used. Windows and Linux restore/build/test were rerun.

Connection pooling retained temporary SQLite files on Windows after tests. Pooling is
production-enabled but explicitly disabled for isolated fixtures and smoke tests, so
cold backup and deterministic cleanup are both exercised correctly.

## Security impact

The database path and artifact directory names are validated, artifact addresses are
canonical lowercase SHA-256 values, stale installation writes return a typed conflict,
and audit rows are globally sequenced and hash-linked. The host still exposes no
autonomous runtime capability. The journal requires `RedactedData`, but redaction is
not assumed complete until the next security gate.

## Portability impact

startup pass under .NET 10.0.302 on Windows 10 and Ubuntu 24.04.
