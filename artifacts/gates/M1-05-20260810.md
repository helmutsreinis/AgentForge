## Security review

Invalid candidates are rejected before durable installation reads. Provider profiles
must be installation-scoped and have observed text capability. `LocalOnly` requires
loopback and forbids fallback. Children cannot exceed parent tokens or configured
depth/count/concurrency. Learning mode and mutable scope must match.

The bootstrap effective definition explicitly denies external network, direct
credential access, messaging, device write, privileged execution, and promotion.
Exact tool/skill grants remain `RequireApproval`; unconfigured authority is absent and
therefore denied. Preview is non-mutating; create performs the same evaluation again
and commits identity plus audit in one unit of work.

## Portability impact

The agent domain and evaluator use no infrastructure SDK types. `UTC` timezone and
loopback provider fixtures behave identically on Windows and Ubuntu. Fully qualified
workspace validation is host-native, and persisted workspaces remain local-install
configuration rather than portable bundle content.
