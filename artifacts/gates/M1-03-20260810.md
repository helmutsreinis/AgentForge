## Security review

The command parser accepts only exact option names, rejects duplicates and missing
values, requires a canonical non-empty optional installation GUID, and never invokes a
shell. Application validation bounds actor/correlation IDs and rejects control
characters. Storage exceptions map to a generic retryable failure without reflecting
exception details. State plus redacted audit commit atomically.

The CLI is a local setup surface, not an authenticated remote mutation. It cannot
validate a provider, create an administrator or agent, or transition to `Ready`.

## Portability impact

Both the interactive and headless process tests execute the actual `agentforge.dll`
through argument arrays under Windows and Ubuntu. Paths containing spaces are
preserved, and the same durable state plus audit-sequence shape is produced.
