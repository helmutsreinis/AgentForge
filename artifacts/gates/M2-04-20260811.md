## Security and portability review

Probe behavior is selected by an immutable descriptor operation kind, not by executable
name, PATH inventory, model request, or caller arguments. Admission rejects ordinary or
parameterized tools, inherited environment, any network access, target authority, side
effects, sensitive output classification, weak sandbox selection, absent network-isolation
evidence, and relaxed time/output limits. The operation kind participates in the canonical
descriptor hash and therefore changes approval identity.

The application service performs exact description only to confirm the operation, then
delegates an empty typed request to `IToolInvocationService`. Current Ready installation,
agent/version, network posture, exact approval, pre-start durable audit, post-commit policy
revalidation, sandbox capability checks, terminal evidence, and fail-closed replay are not
duplicated or bypassed. Output bytes live only in the invocation scope. The complete first
line is decoded strictly and redacted before truncation, preventing a secret split across
the summary boundary.

The deterministic sandbox reports Container and NetworkIsolation on Windows and Ubuntu so
application semantics are fully testable without external infrastructure. It is evidence
for the contract only, not evidence of live OS isolation. Docker and Podman are absent on
the workstation and the production restricted-host adapter correctly cannot satisfy these
probe descriptors.

## Remaining findings

- The live container/namespace adapter and image/network-isolation tests remain open and
  must pass before production composes any probe descriptor.
- Executable bytes can change between catalog admission and process open. Immutable images
  or executable evidence are required before higher-risk tools are enabled.
- No CLI/API/model route exposes probes. Later authenticated contracts must retain exact
  idempotency, approval, rate-limit, output-redaction, and correlation behavior.
- A crash after durable authorization and before terminal evidence remains an uncertain
  invocation and is never automatically replayed.

## Rollback

Remove the probe service registration, contract and records, `AvailabilityProbe` operation
kind and admission rule, tests, and ADR together. Because the operation kind participates
in descriptor hashes, invalidate any out-of-band descriptors and approvals created from
this code; never rewrite hashes or reactivate consumed approvals. No schema rollback is
needed. Leave inventory passive, the production catalog empty, and tool execution disabled.
