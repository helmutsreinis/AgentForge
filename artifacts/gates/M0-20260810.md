## Security impact

The host binds to loopback by default, validates correlation identifiers, treats
missing setup as not ready, treats corrupt state as recovery-required, and blocks
runtime operations until Ready. No model, tool, plugin, network integration, secret,
channel, scheduler, or device capability is enabled.

## Portability impact

The same source and tests build on Windows 10 and Ubuntu 24.04 with .NET 10.0.302.
Default data-directory resolution has deterministic Windows, XDG, and Linux fallback
tests. A repository-local ignored Linux SDK was used because the WSL distribution did
not have a system SDK.

## Remaining findings

- Docker is unavailable locally; container isolation is a named M2 environment gate.
- Installation detection is file-based and read-only in M0. M1 replaces mutation and
  durable ownership with transactional SQLite services.
- Authentication, secret storage, audit persistence, and remote hardening are not yet
  implemented, so runtime remains intentionally disabled.

## Rollback

This is the initial repository slice. After commit, rollback is a normal `git revert`
of the M0 commit. No external service, durable database, credential, or device state
was created.
