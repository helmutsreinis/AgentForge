## Security and portability review

Loading executes nothing and follows no links. Package and per-file byte counts, paths, encodings,
JSON shape, identifiers, dependency graph, permissions, requirements, signatures, and hashes are
bounded before persistence. Default signature trust denies. Markdown remains in the content-addressed
artifact and is disclosed only to an exact valid run snapshot after an integrity recheck.

Proposal actors are distinct, deterministic failures veto, current baseline hashes prevent stale
promotion, and active pointer/status/proposal/audit changes commit atomically. The format, canonical
bundle, state machines, and SQLite behavior are OS-independent.
