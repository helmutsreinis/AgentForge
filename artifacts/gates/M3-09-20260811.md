## Security and portability review

Admission reserves the full worst-case run budget before any provider call and re-reads the exact
agent authority version. Every retry consumes one pre-authorized attempt reservation; total attempts,
tokens, tools, events, wall time, and cost cannot exceed the persisted aggregate. Attempt count is
bounded to eight and agent turns remain independently bounded.

Retry requires a terminal retryable external failure, exact run and attempt versions, an ordered
history containing every previous profile exactly once, a fresh plan, the same request and authority,
and a distinct authorized route. The planner re-applies locality, fallback, capability, health, and
budget rules; failure to produce a route retains the durable failure and makes no call. The next
attempt and retry audit are committed atomically.

Each attempt keeps its reservation, usage, lease, terminal result, provider health, ledger row, and
event evidence. The run stores checked cumulative tokens, cost, event count/hash, and wall time while
preserving the original start time. Currency disagreement or arithmetic overflow fails closed.
Windows and Linux use the same domain and SQLite transitions; migration 0012 is OS-neutral.
