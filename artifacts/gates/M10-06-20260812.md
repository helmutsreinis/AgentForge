## Security and portability

- Release paths are validated, link-free, ordered, timestamp-pinned, content-hashed, and provenance-attested. No signing secret is stored.
- Windows service and Linux systemd user service retain the exact R1 operator identity required by user-scoped secret stores.
- The container is non-root, loopback-only, and has no plaintext secret fallback. Equipped-runner image build/health/SBOM/attestation is a mandatory release job.
- Restore verifies every database/artifact/secret/state file and writes only a separate absent/empty target. PostgreSQL source and target secret variables must differ.

## Rollback

Stop the new host, preserve its directory, verify the pre-upgrade package, and restore it into a separate empty target
with the prior binary and the same OS account. Validate doctor/audit/provider evidence before switching directories.
Never apply a destructive down migration to operator state.
