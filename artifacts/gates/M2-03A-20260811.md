## Security and portability review

The adapter never searches PATH and never accepts a shell command string. Executable and
working paths are normalized and verified through each existing parent before launch.
Arguments are added individually. Environment inheritance defaults empty, request values
must match an administrator-configured allowlist, all streams are redirected, and standard
input is closed. Output observers are serialized with captured chunks and receive the same
cancellation boundary as the execution.

Windows creates a Job Object with kill-on-close before starting the process, attaches the
child immediately after start, recaptures pre-existing descendants from a Tool Help
process snapshot, rechecks until stable, and snapshots/kills managed descendants before
Job termination. Ubuntu uses the .NET managed entire-tree termination
primitive. Both return typed budget failures for timeout
or output overflow, propagate caller cancellation after cleanup, and return retryable
external failure for start/observer faults.

Capabilities are not aspirations. Restricted host reports no filesystem, network, CPU,
memory, process-count, credential, privilege, or container isolation. Requests requiring
any such control fail before start. Docker is absent locally; that does not enable a
fallback and leaves the container live gate open.

## Remaining findings

- Local filesystem entries can be replaced between validation and process start. A later
  descriptor hash check reduces substitution risk; high-risk tools require container or
  namespace isolation.
- Windows uses bounded snapshot/recheck after parent attachment, and managed descendant
  discovery has platform timing limits. Restricted host is not suitable for hostile binaries.
- No caller can reach `ISandbox` through a mutation endpoint. The next slice must source
  risk, executable, schema, side effects, and limits from an immutable descriptor,
  reconstruct current policy, consume exact approval and write audit/outbox state before
  process start.
- Host-network inheritance is an explicit request value, not network isolation. Policy
  must forbid it for local-only or untrusted work.

## Rollback

This slice changes no durable schema. Stop the host, roll back the Host/CLI wiring and
`AgentForge.Tools` project together, and leave tool invocation disabled. No approval,
audit, installation, artifact, or secret state needs transformation. If a process survives
an interrupted controller, terminate it through the OS process tree, retain diagnostic
logs, and do not re-enable the adapter until the containment failure is understood.
