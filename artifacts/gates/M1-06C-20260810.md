## Security and portability review

Credential material never enters command arguments or returned JSON. The CLI reads
at most 16,384 characters, rejects incompatible stdin/prompt modes, passes a character
memory to the service, and clears both its read and invocation buffers. The durable
profile and audit contain an OS store/key reference only; tests scan SQLite for the
exact fixture. Any failed profile commit compensates the newly stored reference.

Edit hashes bind installation, actor, correlation, target, expected installation and
entity versions, normalized effective parameters, and provider capability evidence.
Apply repeats authentication, normalization, duplicate checks, capability validation,
and hash calculation. A successful edit atomically increments the profile and global
installation versions with its audit event. No autonomous runtime starts in recovery.

The service contracts, state machine, repositories, and deterministic tests pass on
Windows and Ubuntu. Windows additionally proves the actual current-user DPAPI path.
Ubuntu's missing live Secret Service remains a typed unavailable capability and never
falls back to plaintext.
