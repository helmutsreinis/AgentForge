## Security and portability review

The router accepts no endpoint, secret, arbitrary header, executable, or model-authored policy.
Exact model and bounded unique attempt exclusions are checked first. Current capability evidence
must support all request modalities; every provided evidence source must be available and fresh.
Locality then excludes cloud candidates before separate current `PolicyApproved` route evidence
is considered. Context/output limits and tool support further narrow the set. Missing, future,
expired, opposed, malformed, or unapproved evidence produces a typed failure.

A viable exact primary always wins. Fallback must be enabled and ranks by reliability descending,
known combined cost ascending, latency ascending, and profile GUID. Unknown cost sorts last. The
immutable result includes required capabilities and a canonical SHA-256 over the model, effective
policy, input/output context requirements, attempt exclusions, selection/fallback state, required
capabilities, and complete selected-provider evidence. Image content is preserved through final
request normalization and cannot be dropped to obtain a route.

The implementation uses only BCL and AgentForge contracts and passed identically on Windows and
Ubuntu. Time comes from `IClock`; catalog, capability, exclusion, and result collections are
snapshotted or read-only, so selection has no platform- or wall-clock-dependent enumeration order.

## Remaining findings

- The pure router trusts a later application service to supply the current effective
  `AgentModelPolicy`; routing evidence is not yet bound to durable agent/profile versions.
- Provider health, bounded retry history, destination DNS/IP revalidation, current profile
  resolution, and failover invocation are not implemented.
- Selection evidence is not an authorization token. Audit, cumulative token/cost reservation,
  immutable run snapshots, cancellation across attempts, and usage reconciliation remain closed.
- Anthropic, DeepSeek, and native/local provider adapters plus specialist extractor routing remain
  future Milestone 3 slices.
- No public API/CLI model route exists, and the production catalog remains empty.
