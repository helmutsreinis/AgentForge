# Gate UI-PREVIEW-01-20260811

Decision: **Pass**

## Scope

An early loopback-only, read-only browser surface for operator review. The page visualizes
installation state, host liveness, runtime readiness, and explicit restricted-sandbox
evidence through existing same-origin GET endpoints. It adds no session, cookie, credential
input, mutation, model invocation, or new application-service path and does not claim the
Milestone 7 authenticated setup wizard.

## Requirements addressed

AF-SET-001 and AF-HOST-002 gain a visual first-run/status adapter. Their existing fail-closed
behavior remains unchanged. AF-SET-002 CLI/web setup equivalence is not claimed: interactive
web setup, nonce/session/CSRF/origin controls, exact idempotency, audit, and rate limiting
remain the Milestone 7 gate.

## Security and portability review

The host remains bound to `127.0.0.1` by default. The page uses static local assets and
same-origin GET requests only. API strings are rendered through `textContent`. There is no
browser credential handling, state-changing route, session, cookie, model output, external
font/script/image, or inline executable content. A restrictive CSP denies external content,
forms, objects, and framing; complementary headers deny MIME sniffing, referrers, selected
ambient APIs, and caching.

The same ASP.NET Core static-files path and integration suite pass on Windows and Ubuntu.
Responsive styles cover compact desktop, tablet, and mobile widths and preserve keyboard
focus, skip navigation, reduced-motion preference, live status announcements, and semantic
headings. The Codex in-app browser client rejected automated loopback navigation with
`ERR_BLOCKED_BY_CLIENT`; the tested host remains available to the operator's local browser
at the reported loopback URL and no broader network binding was introduced to bypass that
client restriction.

## Remaining findings

- This is a status preview, not an authenticated web setup wizard.
- Web setup must not accept credentials or mutations until its nonce/session/CSRF/origin,
  authentication, rate-limit, exact-idempotency, audit, and shared-service equivalence gates
  pass in Milestone 7.
- A later UI acceptance gate needs operator/browser visual evidence at desktop and mobile
  widths; automated in-app capture cannot currently reach this process-local URL.
- Remote binding remains explicit and is unsafe until Milestone 10 remote-mode hardening.

## Rollback

Remove `wwwroot`, the static-file and browser-header middleware, the three host integration
assertions, ADR 0020, the visual-preview documentation entries, and this report. No database
migration, package, durable state, credential, external service, or remote artifact requires
reversal.
