## Security review

Redaction recognizes normalized credential field names and conservative suffixes,
plus bearer, OpenAI-style, GitHub, Slack, AWS access-key, JWT, connection-string, and
private-key shapes. Payload bytes and JSON depth are configurable but bounded.
Objects are key-sorted and hashes encode every field with a length prefix before
SHA-256, avoiding newline/delimiter ambiguity.

The lower-level redacted journal contract remains available to infrastructure and
fixtures; application features must use `IAuditRecorder`. No provider, model, export,
tool, channel, or device sink is enabled yet.

## Portability impact

The same redaction output, hash chain, tamper decisions, complete suite, and live host
startup pass on Windows 10 and Ubuntu 24.04 with .NET 10.0.302.

Because Windows and WSL share one checkout, Linux restore rewrites generated `obj`
assets with Linux package-cache paths. The final Windows formatter initially could
not resolve those paths; a locked Windows restore repaired the design-time graph and
format verification passed. The runbook now requires a platform-local restore after
every platform switch.
