## Security review

Secrets never become provider-profile fields. DPAPI uses `CurrentUser`; plaintext and
decrypted byte buffers are zeroed. Secret leases clear character arrays on disposal.
The Linux adapter uses an absolute executable, `ArgumentList`, an environment
allowlist, redirected stdin, bounded stdout/stderr, cancellation, timeout, and process
tree termination. Missing OS support is explicit and cannot silently degrade.

Provider endpoints forbid user info, query, and fragment components. Profile rows are
foreign-key scoped to installation and uniquely named. The deterministic store is a
named fake used by tests; production composition selects only the OS adapter.

proves this workstation's absent `secret-tool` is reported safely. All provider,
migration, restore, audit, and plaintext-absence fixtures are otherwise identical.
